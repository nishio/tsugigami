      設定

      非公開の repo を作り、fine-grained token を発行して貼ってください。 Repository access は「Only select repositories」でその repo だけ、Permissions は「Contents: Read and write」だけで足ります。 トークンはこの iPad の中にだけ保存されます。

      ファイルへの書き出し

      ノートはまずこの iPad の中に保存されます。GitHub を設定していないときは、ときどき書き出して、ファイル アプリなどに保管してください。
