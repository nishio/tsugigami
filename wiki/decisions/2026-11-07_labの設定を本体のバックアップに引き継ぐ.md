# lab に入れた GitHub の設定を、本体の自動バックアップに引き継ぐ

## 何が起きていたか

- nishio は lab(`?lab=1`)のパネルに repo とトークンを入れて、それで GitHub の設定が済んだと思っていた([raw](../../raw/2026-11-07_labのトークンが本体に引き継がれていなかった.md))。
- 実際には、lab は入れた設定を **lab の保存領域**(IndexedDB `tsugigami-lab` の `lab:github`)にだけ保存していた。lab は本体の設定を読みに行くが、逆向きには書かない。
  - 読む向きは [lab の判断](2026-10-28_iPad自身を実験機にする.md) に書いてあった。書かない向きはどこにも書いていなかった。
- そのため本体の自動バックアップは未設定のままだった。iPad のノートは一度も `nishio/tsugigami-notes` に届いていない。その repo の最後の commit は 2026-10-30 の lab の結果で、`notes/` は無い。
- 未設定であることは、ノート一覧の下の方にある「GitHub への自動バックアップ」の欄にしか出ていなかった。赤い点も、7 日以内に書き出していれば出ない。

## 選んだこと

1. **本体の起動時に聞く。** 本体が未設定で、lab の保存領域に設定があるとき、画面の上に次の問いを出す:
   - 文面は「lab に入れた設定(repo 名)で、ノートの GitHub への自動バックアップを始めますか？」。ボタンは「始める」と「しない」。
   - 「始める」で `auto.configure` に渡す。設定を確かめて、すぐ送る。
   - 「しない」なら、次の起動からは聞かない(本体の `github:labOffer` に記録する)。ノート一覧のボタン(2.)からは、いつでも始められる。
   - トークンが失効していてつながらなければ、失敗を知らせる。ノート一覧の「設定する」へ案内する。
2. **未設定の間は、ノート一覧の先頭に出し続ける。** 「GitHub へのバックアップは未設定です。書いたものはこの iPad の中にしかありません。」と出す。
   - 下に「lab の設定で始める」(lab に設定があるとき)と「設定する」(設定欄を開く)のボタンを並べる。
3. **lab で新しく入れるときは、本体にも使うかを聞く。** lab の入力欄に「本体のノートの GitHub へのバックアップにも使う」のチェックを付けた。既定はオン。
   - オンなら、本体が未設定のときに限り、本体の保存領域へ設定を書く。本体は次に開いたときに送り始める。
4. **トークンの値は出さない。** 画面に出すのは repo 名だけにした。e2e で、ページの HTML にトークンの文字列が無いことを確かめている。
5. **lab を開いたことがない端末では、lab の保存領域を作らない。** 先に `indexedDB.databases()` で、保存領域があるかを見る。

## 却下した案

- **聞かずに引き継ぐ。**
  - 書く手間は一番少ない。
  - しかし、lab の設定は実験の結果を置くためのものとして入れたものである。ノートを同じ repo へ送ってよいかは本人が決める。依頼も「尋ねる」だった。
- **本体と lab で保存領域を一つにする。**
  - lab は本物のノートに触らないために保存領域を分けている([lab の判断](2026-10-28_iPad自身を実験機にする.md))。分けたまま、設定だけを渡す方を選んだ。
- **未設定の間、赤い点を常に出す。**
  - 赤い点は「守れていないかもしれない」の印で、今は書き出しから 7 日を過ぎたかで決めている。意味を変えずに、ノート一覧の先頭の表示で知らせる方を選んだ。
  - nishio が一覧を開かないまま気づかない、ということが続くなら見直す。

## 確かめたこと

- **自動テスト**(`e2e/lab-config.spec.ts`、偽の GitHub、WebKit と Chromium)で次を確かめた:
  - lab の保存領域にだけ設定がある状態から、本体を開くと聞かれる。承諾すると `notes/<id>/p0001.json` が commit され、lab の結果(`experiments/`)は残る。
  - 「しない」の後は、再読み込みしても聞かない。ノート一覧の「lab の設定で始める」から始められる。
  - lab の「本体にも使う」がオンなら、本体は聞かずに設定済みになっている。
  - lab を開いたことがなければ聞かない。lab の保存領域も作らない。
- **実機ではまだ。** iPad の `lab:github` に、本当にトークンが残っているか(窓口のセッションの見立て)。そのトークンが今も有効か、`nishio/tsugigami-notes` の Contents に書けるか。
