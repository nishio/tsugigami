# UI フレームワークを使わない

## 決めたこと

TypeScript + Vite だけで書き、React などの UI フレームワークは入れない。

## 理由

- 中心はキャンバスへの描画で、ホットパス(pointermove → 描画)に仮想 DOM や状態管理を挟みたくない。
- UI 部品は道具バー、ノート一覧、選択メニュー、継ぎ足しボタン程度で、手で DOM を書いても小さい([main.ts](../../src/main.ts) で約 400 行)。
- ビルド成果物が小さい(JS 約 37KB)。オフライン用のキャッシュも軽い。

## 見直す条件

設定画面や同期の状態表示などで UI が膨らみ、main.ts の手書き DOM が辛くなったら、UI 部分だけに軽いライブラリ(Preact など)を入れることを検討する。描画と入力には入れない。
