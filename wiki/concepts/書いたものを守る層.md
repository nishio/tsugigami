# 書いたものを守る層

「ここに書いたものが消えないと信じられること」([raw](../../raw/2026-10-27_消えないと信じられること.md))は、日常のノートを tsugigami に切り替えるための前提条件である。

1 つの仕組みで全部は守れない。失い方ごとに、別の層で守る。

| 層 | 守るもの | 失い方 | 仕組み |
|---|---|---|---|
| 画面(Doc) | 書いた直後の線 | — | 線を確定した瞬間に Op として適用し、保存の列へ並べる |
| 保存の列 | まだ IndexedDB に入っていない線 | 接続切れ、一時的な失敗 | 開き直して成功するまで再試行する。失敗中は赤い帯で知らせる([finding](../findings/SafariのIndexedDB接続切れ.md)) |
| IndexedDB | iPad の中のすべて | ブラウザによる削除、アプリの削除、端末の故障 | `persist()` の申請。ホーム画面アプリは 7 日での削除の対象外とされる(未確認) |
| GitHub の repo | iPad の外の写し | 手元が全部消える | 手を止めるたびに自動で commit する([判断](../decisions/2026-10-27_GitHubの非公開repoへ自動バックアップ.md)) |
| git の履歴 | 過去のどの時点でも | 間違えて消した、壊れた内容を送った | commit を重ねるだけで、上書きで消えない |
| 書き出したファイル | 人が持ち出した写し | GitHub が使えない | 手動の書き出し・読み込み |

## 設計の約束

- **失敗を黙って捨てない。** 保存できていない間は、消えない表示で知らせる。
- **手元が空でも、外の写しを消さない。** 外の写しを消すのは、人が「完全に削除」したときだけ。
- **戻し方を用意する。**
  - GitHub から読み込める。
  - ファイルから読み込める。
  - どちらも、手元より新しいノートだけを取り込むので、何度やっても増えない。
- **書き味を邪魔しない。** 保存は線 1 本ぶんの差分だけ。GitHub へは手が止まってから送り、ペンが触れている間は始めない。

## まだ守れていないもの

- 画面上で消しゴムやゴミ箱の「完全に削除」で消したもの。取り消しの履歴はアプリを閉じると消える。ただし GitHub に一度送った後なら、git の履歴から戻せる。
- 書いて 20 秒以内にアプリが落ちた場合、その分は iPad の中にしかない。
