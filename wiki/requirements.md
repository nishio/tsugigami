# 要件

nishio の発言([raw](../raw/2026-10-27_Notability置き換えの要件会話.md))から合成したもの。✅ は M1 で実装済み(実機未確認)。

## やめたいこと(Notability から離れる理由)

- 起動時にクラウドサービスの案内画面などが出て邪魔。✅ 何も出さず、前回のノートの前回の位置を開く。
- いらない機能が増えてきた。→ 機能を足すときは「nishio がよく使う」と言ったものか、データを守るためのものに限る。

## 紙のかたち

- 無限キャンバスだが、A4 縦がずっと縦に繋がっている形で使っている。✅
- 横幅が足りなく感じることがあるので、任意に横に追加できるとよい。**その箇所だけ右に広がる**イメージ(その行から下が全部広がるのではない)。✅ ページ単位で右へ継ぐ([判断](decisions/2026-10-27_横の継ぎ足しはページ単位.md))。
- 1 次元の縦スクロールで書いていくと、時間軸という暗黙の整理軸ができてよい([縦スクロールの時間軸](concepts/縦スクロールの時間軸.md))。

## よく使う道具

| 道具 | 状態 |
|---|---|
| 黒ペンでの筆記(メイン) | ✅ |
| 赤・青のペン | ✅ |
| 半透明のマーカー | ✅ 赤・青・緑・黄・薄い灰・濃い灰。乗算で重ね、インクの下に塗る。既定は太([issue #1](decisions/2026-10-27_Notabilityの書き味に合わせる.md)) |
| 見た目を Notability の設定に合わせる(issue #1) | ✅ 筆圧なし・中くらいの太さ・見本から採った配色([判断](decisions/2026-10-27_Notabilityの書き味に合わせる.md)) |
| パスに触れるとパスを消す消しゴム | ✅ |
| 投げ縄選択 | ✅ 点の半分以上が内側の線を選ぶ |
| 拡大縮小・回転・コピー・ペースト | ✅ 切り取り・複製・削除・色変えも |
| 方眼紙モード | ✅ 5mm 方眼、ノートごとに切り替え |
| 手を置いたまま書いても紙が動かない | 🔶 議事録で「拡大縮小のずれが頻発」(2026-10-30)。実機の記録から、同時 3 点以上と pointercancel を手とみなす規則にした([判断](decisions/2026-10-30_手の群れとpointercancelで見分ける.md))。タップの最短時間も記録から決めた。記録の再生では直った。実機で確認待ち |

## 優先度の付け方

- 「明日から Notability の代わりに使える完成度」が目標。新機能より、**書いたものが消えないこと**と**毎日使う道具がそろっていること**を優先する。
- 同期は後回しでよい(nishio 確認済み)。代わりにバックアップの書き出し・読み込みで守る([判断](decisions/2026-10-27_同期は後回し_バックアップで守る.md))。
- **書いたものが消えないと信じられること**(日常のノートを切り替える前提。nishio、2026-10-27)。→ 保存の再試行と、GitHub の非公開 repo への自動バックアップ([判断](decisions/2026-10-27_GitHubの非公開repoへ自動バックアップ.md)、[書いたものを守る層](concepts/書いたものを守る層.md))。✅ 実装、iPad では未確認
- Kozaneba との連携: 手書きを Kozaneba で並べ替えたい。画像のままでよい。ただし今すぐではない([Kozaneba との関係](themes/Kozanebaとの関係.md))。
- リポジトリは公開でよい(nishio 確認済み)。ノートのデータはリポジトリに入らない。
