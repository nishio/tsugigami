# tsugigami の全体像

## 何か

nishio が iPad + Apple Pencil で毎日使う手書きノートを、Web 技術(PWA)で自作したもの。Notability の置き換えが当面の目標。名前は「継ぎ紙」から。A4 を縦に継ぎ足して 1 本の帳面にし、必要な箇所だけ右へ紙を継ぐ([継ぎ紙モデル](concepts/継ぎ紙モデル.md))。

## なぜ作るか

Notability の起動時にクラウドサービスの案内が出て邪魔で、いらない機能が増えてきたから([要件](requirements.md))。だからこのアプリは**起動したらすぐ前回の紙が出る、余計なものを出さない**ことを最初の約束にしている。

## 現在地(2026-11-07 更新)

- M0(骨組み)と M1(明日から使える版)を一晩で実装。ペン・マーカー・線消しゴム・投げ縄(移動/拡大縮小/回転/コピー/切り取り/複製/削除/色変え)・貼り付け・方眼・ページの右への継ぎ足し・ノート一覧とゴミ箱・バックアップの書き出しと読み込み・オフライン起動。
- nishio が実機で使い始めた(2026-10-27)。書く速度は問題なし。見た目を Notability の設定に合わせた(issue #1)。
- 「書いたものが消えないと信じられる」ことを最優先にして、保存の再試行と GitHub の非公開 repo への自動バックアップを入れた([書いたものを守る層](concepts/書いたものを守る層.md))。
- iPad 自身を実験機にする lab(`?lab=1`)を入れた(2026-10-28、[判断](decisions/2026-10-28_iPad自身を実験機にする.md))。AI が送ったスクリプトを本物の Safari で走らせ、結果を受け取る。
- 線のガタつき(issue #2): 保存された点列は Notability と同等に滑らか。正体は書いている最中のライブ層の描き方で縁のアンチエイリアスが潰れること、までは分かった。iPad でペンを離した後も残る理由は未切り分け([計測](findings/線のガタつきの計測.md))。
- 手のひら判定: 議事録で「拡大縮小のずれが頻発」(2026-10-30)。lab で置いた手・ピンチ・スクロール・タップを記録し、同時 3 点以上と pointercancel を手とみなす規則と、タップの最短時間 30ms をデータから決めた([判断](decisions/2026-10-30_手の群れとpointercancelで見分ける.md))。新版での実機の感想待ち。
- 2026-11-06 の感想 6 項目([raw](../raw/2026-11-06_iPadで使った感想_パームのundo_fit_アイコン_題名.md))を反映: 指のタップのジェスチャーを外した、fit(紙の幅 = 画面幅)を通常の表示にした、継ぎ足しと fit を紙の左のメニューに、ペンとマーカーのアイコン、新しいノートの題名 `ノート(作った日~)`。GitHub Pages への公開は 2026-11-06 の Actions(9d091d7)で済んでいる。どれも実機で未確認。
- 確認待ちの項目は [実機でしか分からないこと](themes/実機でしか分からないこと.md)。GitHub の issue(2026-11-07 に確認): #1(テイスト)は 2026-11-07 に nishio のアカウントで閉じられた(コメント「8ad1699(2026-10-27)で反映しました」。実機で確かめた記録ではない)。#2(線がガタガタ)と #3(描き始めのパームリジェクション、[raw](../raw/2026-10-28_issue3_描き始めのパームリジェクション.md))は open。#3 の後半「通常のモードでキャンバスが左右に少し動くことができるのはおかしい」は、11/06 の fit(縦にだけ動く)と同じ向きの要望。(2026-11-03 の時点では #1 も open だった)

## 構成

| 層 | 中身 | コード |
|---|---|---|
| データ | ノート、ページ、ストローク | [model.ts](../src/model.ts) |
| 幾何 | 当たり判定、投げ縄、アフィン変換 | [geom.ts](../src/geom.ts) |
| 文書 | 空間索引、操作(Op)、取り消し履歴 | [doc.ts](../src/doc.ts) |
| 保存 | IndexedDB(書き込みの列と再試行)、ファイルへの書き出し | [store.ts](../src/store.ts) |
| 外への写し | GitHub の repo への自動バックアップと復元 | [github.ts](../src/github.ts)、[autobackup.ts](../src/autobackup.ts) |
| 描画 | タイルキャッシュ、紙と方眼、ストロークの描き方 | [render.ts](../src/render.ts) |
| 入力 | ペン・指・手のひら判定・選択と変形 | [controller.ts](../src/controller.ts) |
| 画面 | 道具バー、ノート一覧、選択メニュー、紙の左のメニュー(継ぎ足し・fit) | [main.ts](../src/main.ts) |
| 実験機(lab) | `?lab=1` のときだけ動く。非公開 repo の待ち行列からスクリプトを拾って実行し、結果を commit する | [lab/api.ts](../src/lab/api.ts)、[lab/index.ts](../src/lab/index.ts)、[lab/repo.ts](../src/lab/repo.ts) |

描画の考え方は [描画の層とタイル](concepts/描画の層とタイル.md)、保存の考え方は [線ごとに IndexedDB へ保存](decisions/2026-10-27_線ごとにIndexedDBへ保存.md)。
