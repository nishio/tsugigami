# 実機でしか分からないこと

自動テストでは確かめられず、nishio が iPad + Pencil で確かめるしかない項目の一覧。確かめた結果は `raw/` に感想として保存し、ここと関連ページを更新する。

## 最初に見てほしいこと

0. **GitHub への自動バックアップの設定**: ノート一覧 →「GitHub への自動バックアップ」→「設定」に、repo `nishio/tsugigami-notes` と fine-grained token を入れて「保存して試す」。少し書いてから GitHub の repo に commit が増えるか。

1. **書き味**: 黒の細ペンで普段の速さで字を書いて、Notability と比べて線の遅れが気になるか。
2. **手のひら**: 手を画面に置いたまま書いて、紙が勝手に動かないか。
3. **起動**: ホーム画面から起動して、案内なしに前回の紙がすぐ出るか。機内モードでも起動するか。
4. **バックアップ**: 「書き出す」で共有シートが出て、ファイル アプリに保存できるか。
5. **長いノート**: 何ページも書いたあと、スクロールとズームが重くならないか。

## lab で AI から頼めること(2026-10-28〜)

iPad で `?lab=1` を開いておけば、AI がスクリプトを送って本物の Safari 上で実験できる([決定](../decisions/2026-10-28_iPad自身を実験機にする.md))。合成のペン入力と画面の撮影は自動、Pencil で書く手順は「次へ」を押す人の手が要る。画面そのもの(コンポジタ)の確認だけは、引き続きスクリーンショットを頼む。

## 計測値の見方

ノート一覧の一番下「書き味の計測」に、直近のストロークの move イベント数・点の数・JS に届くまでの時間と、各機能(合体イベント・予測イベント・低遅延キャンバス・ホバー)の有無が出る。値を教えてもらえれば [iPad の Web アプリの制約](../findings/iPadとWebの制約.md) を確定させられる。
